# Product wishlist

Зафиксированные идеи и пожелания по развитию General:

- добавить музыку с плеером в профиле и отдельной аудиотекой;
- в видео сделать плейлисты «Избранное», «Просмотренные» и «Смотреть позже»;
- сделать рабочий поиск из главной шапки по пользователям, постам и видео;
- сохранить идеи для будущих разделов: друзья онлайн, комментарии с ответами, музыка в профиле;
- продолжать держать интерфейс в стиле VK: мягкие скругления, понятные блоки, аккуратная плотность информации.
